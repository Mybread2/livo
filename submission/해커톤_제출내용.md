## 2. 해결하고자 한 문제 (한 줄)

**성대 마비·ALS 등으로 발성이 어려운 사람이 입모양만으로 원하는 말을 즉시 음성으로 출력할 수 있는 보완대체 의사소통(AAC) 수단이 없다.**

---

## 3. AI 활용 방식 및 결과 (500자 이내)

입모아는 AI를 두 축으로 활용합니다.

**첫째, 브라우저 내 실시간 입술 인식.** Google MediaPipe Face Landmarker로 카메라 영상에서 468개 얼굴 랜드마크를 매 프레임 추출하고, 입술 좌표 변화 패턴을 사전 등록 템플릿과 DTW(동적 시간 워핑)로 비교해 발화 문장을 판정합니다. 모든 추론이 브라우저 안에서 완결되어 카메라 영상이 서버에 전송되지 않습니다.

**둘째, ElevenLabs 음성 합성으로 개인화된 목소리 출력.** 보호자가 선택한 프리셋 목소리로 등록 문장을 사전 합성해 기기에 캐시합니다. 인식이 완료되면 네트워크 없이 즉시 재생되어 응급 발화도 지연 없이 동작합니다.

## 4. 사용 AI 툴 및 기술 스택 — 체크 목록

### ✅ 체크해야 할 항목

| 항목 | 근거 |
|------|------|
| **Next.js** | App Router 기반 프레임워크 (package.json) |
| **React** | UI 렌더링 (package.json) |
| **Claude** | 전체 개발에 Claude Code(AI 코딩 어시스턴트) 활용 |
| **Vercel** | 프로덕션 배포 플랫폼 |
| **Supabase** | Auth(Google OAuth) · Postgres DB · Storage |
| **ElevenLabs** | 음성 합성 API (src/services/elevenlabs.ts) |

### ❌ 체크하지 않을 항목 (미사용)
ChatGPT, Gemini, Cursor, GitHub Copilot, v0, Vercel AI SDK, OpenRouter, Replicate, Whisper, LangChain, Pinecone, Figma, Lovable, Midjourney, Hugging Face

> **참고:** MediaPipe는 목록에 없지만 핵심 AI 기술입니다. AI 활용 방식 서술란에 명시하세요.
