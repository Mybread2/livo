# PRD: 리보 (Livo)

> 원본: `리보_개발기획서_v5.html` (2026-09-15). 구현에 필요한 부분만 추렸다.

## 목표
발성을 잃은 사람이 손을 쓰지 않고 입모양만으로, 자기 목소리에 가까운 음성으로 말할 수 있게 한다.

## 사용자
| 역할 | 누구 | 하는 일 |
|------|------|---------|
| 대상자 (subject) | 발성을 잃은 사람 — ALS·운동신경질환, 뇌졸중, 후두 절제·기관절개 | 입모양으로 말한다. 손을 못 쓸 수 있다 |
| 계정 소유자 (account) | 보호자·간병인 또는 본인. Google 계정으로 로그인 | 동의 제출, 목소리·문장 관리, 결제 |
| 대화 상대 | 가족·의료진 | 화면의 문장을 보고 소리를 듣는다 |

- 계정 1개에 대상자 N명(요양기관 대비).
- 병상 옆 태블릿은 영구 로그인 + 키오스크 모드로 고정한다. 대상자는 로그인하지 않는다.

## 핵심 기능 (Stage 1 · MVP)
1. **온보딩** — Google 로그인 → 동의 수집(생체정보·음성·국외이전·법정대리인) → 카메라·조명 체크(얼굴보다 낮게, 올려다보는 각도로 거치) → 캘리브레이션 녹화 → 프리셋 목소리 선택 → 첫 발화 테스트.
2. **점진 캘리브레이션** — 화면이 문장을 띄우면 대상자가 소리 없이 따라 한다. 다음 문장 진행은 발화 구간 검출로 자동(손 사용 0회). Tier 0 응급 4문장 × 3회(약 4분)만으로 첫날부터 쓰고, 이후 세션에서 15문장까지 늘린다.
3. **고정 문장 발화 · 모드 A (기본)** — 무조작 자동 감지. 입 움직임 → 구간 검출(0.5초 정지) → 인식 → 판정 게이트 → 문장 크게 표시 + 미리 합성한 음성 재생. 전부 단말에서, 오프라인에서도 동작.
4. **수동 세션 · 모드 B (옵션)** — ON/OFF 토글. 화면 버튼 외에 BLE 버튼·발 스위치·시선 고정 2초로도 매핑. OFF면 카메라 트랙 정지. 발화 임계값 0.80.
5. **목소리 프로필** — 프리셋 · 동성 가족 · 본인 옛 음성. 등록하면 고정 문장 전체를 사전 합성해 단말에 내려받는다. 교체 중에는 새 오디오를 다 받을 때까지 이전 목소리로 나간다.
6. **인식 방식 비교** — DTW 템플릿 매칭과 소형 1D-CNN을 같은 파일럿 데이터로 비교해 하나로 확정한다(ADR-004).
7. **데이터 수집 도구** — 캘리브레이션 녹화와 연구 수집을 같은 포맷으로 국내에 저장한다. 연구 수집은 소리 낸/무성 쌍 녹화, 연구 영상 동의 시 입 영역 크롭 포함.
8. **발화 로그 동기화** — 단말에 쌓았다가 연결되면 올린다. 좌표·오디오는 저장하지 않는다.

### 고정 문장 15개 (설계 가설 · 파일럿 혼동행렬로 교정)
| Tier | 문장 |
|------|------|
| T0 응급 | 아파요 · 숨이 안 쉬어져요 · 도와주세요 · 약이요 |
| T1 생리 | 화장실 · 물이요 · 배고파요 · 추워요/더워요 중 하나 |
| T2 환경 | 자세 바꿔주세요 · 불 꺼주세요 · 시끄러워요 |
| T3 소통 | 네 · 아니요 · 고마워요 · 잠깐만요 |

- 응급 문장은 빈도와 무관하게 무조건 포함한다(최적화 대상이 아니라 제약).
- "네/아니요"는 눈깜빡임·끄덕임 신호로 분리하는 방향이다(MediaPipe blendshape·머리 자세). 입모양은 보조.
- 고정 문장은 30개를 넘기지 않는다. 그 너머는 자유 문장 트랙이 맡는다.

### 제품 제약
- 응급 발화(Tier 0 + 프리셋)는 결제 실패·구독 만료와 무관하게 항상 동작한다(응급 플랜 영구 무료).
- 동의서에는 철회 범위를 첫 수집 전에 적는다: 철회 시 원본과 추출 좌표·영상은 파기, 이미 학습이 끝난 모델은 제외, 이후 학습에는 사용하지 않음.

## Stage 1 통과 조건
- 등록 문장 정확도 목표 달성 **그리고** 자연 상태 10분 오발화 0회. 둘 다 실제 대상자 파일럿으로 확인한다.

## MVP 제외 사항
- 자유 문장 트랙(후보 3개 + 대화 맥락 + 확인 후 발화) — Stage 3. Stage 1에서는 데이터 수집만 시작한다
- 공용 인코더 학습, 입력 표현(좌표 vs 입 영역 영상) 확정 — Stage 2
- 카카오 로그인 — Stage 2 검토
- 결제·구독 — 기획서 로드맵의 Stage 1 범위에 없다(요금제 정의는 §12.3). 포함 여부는 팀 확인
- 자체 호스팅 TTS — 기능이 아니라 원가·슬롯 최적화 옵션
- 화면이 꺼진 상태의 인식 — 브라우저에서 불가, 네이티브 앱이 필요
- 진단·치료·예후 판정, 임상 효과 표방

## 디자인
- 대상자 화면: 대기 중 검은 화면, 인식된 문장은 크게, 손 없이 완결
- 보호자 화면: 고령 사용자 기준
- 상세는 `docs/UI_GUIDE.md`
