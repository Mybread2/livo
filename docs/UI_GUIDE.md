# UI 디자인 가이드

> 근거: 기획서 v5 §3(사용자 흐름) · §4(트리거) · §14.2(자유 문장 확인). 색상·타이포그래피 수치는 기획서에 없어 미정이다.

## 화면은 두 종류다
| 화면 | 사용자 | 입력 | 기준 |
|------|--------|------|------|
| 대상자 화면 | 발성을 잃은 사람 (병상 태블릿 · 키오스크 모드) | 입모양 · 반복 발화 · 눈깜빡임·끄덕임 · 외부 스위치 | 손 없이 완결 |
| 보호자 화면 | 보호자·간병인 (고령 포함) | 터치 | 로그인 · 동의 · 목소리 · 문장 관리 |

## 디자인 원칙
1. **대상자 화면은 손 없이 끝난다.** 확인 버튼·모달·토스트처럼 터치를 기다리는 요소를 두지 않는다. 캘리브레이션의 다음 문장 진행도 발화 구간 검출로 자동 전환한다.
2. **인식된 문장은 크게 띄운다.** UI 취향이 아니라 안전장치다. "아파요"가 "고마워요"로 나가는 사고를 막는 유일한 수단이 옆 사람의 눈이다. 텍스트와 소리를 동시에 낸다.
3. **대기 중에는 아무것도 없다.** 검은 화면을 유지한다. 화면 자체는 Wake Lock으로 켜둔다 — 꺼지면 브라우저가 카메라를 멈춘다.
4. **실패를 대상자에게 알리지 않는다.** 저확신 인식은 조용히 폐기한다. 대상자는 무엇을 잘못했는지 알 필요가 없고, 못 알아들었으면 다시 말하면 된다.
5. **발화 앞에 아무것도 끼우지 않는다.** 응급 발화 앞에 안내음·로딩·전환 애니메이션을 넣지 않는다. AI 생성 음성 고지는 화면 표시·설정 고지로 한다(이행 방식 법률 검토 중 · W7).

## 대상자 화면 상태
| 상태 | 화면 | 소리 |
|------|------|------|
| 대기 | 검은 화면 | 없음 |
| 캘리브레이션 | 따라 할 문장 1개를 크게. 진행은 자동 | 없음 |
| `discard` (NONE · 거리 초과 · score < 0.70) | 변화 없음 | 없음 |
| `show` (0.70–0.90) | 문장을 크게 표시하되, 소리가 나지 않았음을 구분할 수 있게 | 없음 |
| `speak` (≥ 0.90, 수동 세션 0.80) | 문장을 크게 표시 | 사전 합성 음성 |
| 수동 세션 OFF | 말하기가 꺼져 있음을 표시 (카메라 정지) | 없음 |
| 오프라인 | 고정 문장 발화는 평소와 같다 | 평소와 같음 |
| 자유 문장 후보 (Stage 3) | 후보 3개를 크게. 반복·눈깜빡임·끄덕임으로 선택 | 확정 후에만 |

## 안티패턴 — 하지 마라
| 금지 사항 | 이유 |
|-----------|------|
| 대상자 화면의 확인 버튼·모달·토스트 | 손을 못 쓰는 대상자가 막힌다 |
| 발화 문장 표시 전 fade·slide 애니메이션 | 발화 지연 예산(약 0.6초)을 잡아먹는다 |
| 응급 발화 앞 안내음 | 응급 상황에서 제품이 망가진다 |
| "치료·개선·호전" 등 효능 문구 | 의료기기 광고 규제 대상. 목적은 "의사소통 보조" |
| backdrop-filter: blur() | glass morphism은 AI 템플릿의 가장 흔한 징후 |
| gradient-text (배경 그라데이션 텍스트) | AI가 만든 SaaS 랜딩의 1번 특징 |
| "Powered by AI" 배지 | 기능이 아니라 장식. 사용자에게 가치 없음 |
| box-shadow 글로우 애니메이션 | 네온 글로우 = AI 슬롭 |
| 보라/인디고 브랜드 색상 | "AI = 보라색" 클리셰 |
| 모든 카드에 동일한 rounded-2xl | 균일한 둥근 모서리는 템플릿 느낌 |
| 배경 gradient orb (blur-3xl 원형) | 모든 AI 랜딩 페이지에 있는 장식 |

## 색상 · 타이포그래피 · 컴포넌트 — 미정
기획서에 수치가 없다. 정하기 전까지 아래 제약만 지킨다.
- 대기 화면 배경은 순수 검정.
- 대상자 화면의 문장 텍스트는 병상 옆 사람이 떨어진 자리에서 바로 읽을 수 있는 크기와 대비로 한다. 구체 크기는 파일럿에서 정한다.
- 보호자 화면은 고령 사용자 기준으로 글자와 터치 영역을 크게 한다.
- 위 안티패턴 표의 장식을 쓰지 않는다.
